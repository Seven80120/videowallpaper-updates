# VideoWallpaper

> Fond d'écran vidéo pour Windows — *Video wallpaper for Windows*

---

## 🇫🇷 Français

**VideoWallpaper** est une application Windows qui vous permet de définir une vidéo comme fond d'écran, directement derrière le bureau Windows, sans affecter les performances du système.

### Fonctionnalités

**Version gratuite**
- Vidéo en fond d'écran sur un écran (formats MP4, MKV, AVI, MOV, WEBM…)
- Contrôle du volume et des FPS (jusqu'à 20 FPS)
- Boucle, accélération GPU
- Démarrage automatique avec Windows

**Version PRO — 4,99 €**
- Multi-écrans illimités avec paramètres indépendants par écran
- Playlist avec rotation automatique et intervalle configurable
- Mode vidéo étendue sur plusieurs écrans (Span)
- Jusqu'à 60 FPS
- Filtres en temps réel : vitesse, luminosité, contraste, saturation
- Pause automatique sur batterie
- Sans filigrane
- Mises à jour automatiques

### Configuration requise
- Windows 10 / 11 (64 bits)
- GPU compatible DirectX

## 🇬🇧 English

**VideoWallpaper** is a Windows application that lets you set a video as your desktop wallpaper, displayed directly behind the Windows desktop without affecting system performance.

### Features

**Free version**
- Video wallpaper on one screen (MP4, MKV, AVI, MOV, WEBM…)
- Volume and FPS control (up to 20 FPS)
- Loop, GPU acceleration
- Auto-start with Windows

**PRO version — €4.99**
- Unlimited multi-monitor support with independent settings per screen
- Playlist with automatic rotation and configurable interval
- Span mode — stretch one video across multiple screens
- Up to 60 FPS
- Real-time filters: speed, brightness, contrast, saturation
- Auto-pause on battery power
- No watermark
- Automatic updates

### Requirements
- Windows 10 / 11 (64-bit)
- DirectX-compatible GPU
